# 單字大挑戰

給學生用的英文單字測驗網頁。單一 HTML 檔，開啟即可使用，不需要安裝任何東西。

單字取自中文英語教材《Chapter 1 基礎 1,200 單字》，依 Topic 編號分單元。

## 身分與紀錄系統（v8 起）

打開網頁第一件事是選身分：**我是學生** 或 **我是老師**。選好之後這台裝置會記住，
下次直接進入；主頁上的「切換身分」可以隨時換。

兩種身分**各自有一本獨立的紀錄**，所以老師自己試做題目不會混進學生的統計裡。

**學生**看到的是原本的三種模式，加上自己的錯題紀錄與「錯題重練」。

**老師**多一個「學生學習報告」，內容包含：

- 常錯單字數、累計答錯次數、平均正確率
- 各單元弱點（依答錯次數排序的長條圖）
- 哪種題型最容易錯（英翻中／中翻英／克漏字）
- 常錯單字清單：單元標籤、錯在哪種題型、最近答錯時間
- 歷次作答紀錄：日期、模式、分數、等第
- 清除學生紀錄（需按兩次確認）
- 匯入學生回報碼（見下）

### 例句

每個單字都有**至少 2 句例句**，出克漏字時隨機挑一句，避免學生背句子而不是背單字。

改例句請改 `data/alt-sentences.json`，然後跑：

```bash
node tools/apply-alt-sentences.js && node tools/validate.js
```

驗證會擋掉：沒有 `___`、句子裡出現答案（送分題）、與第一句重複、過短、
以及**與同字的另一句太相似**（詞彙重疊率 ≥0.35 就不算另一種句型）。

### 老師想在自己的裝置上看報告

**方式一：自動同步（需先設定，見 `SETUP-FIREBASE.md`）**

設定完成後，學生做完測驗自動上傳，老師打開報告頁自動抓最新，雙方都不用動手。
預設是關閉的（`SYNC_CONFIG.enabled = false`），關閉時完全不影響其他功能。

**方式二：回報碼（不需要任何設定，也是同步失敗時的備援）**

1. 學生在錯題紀錄面板按「📤 產生回報碼給老師」，把整段代碼傳給老師（LINE 或任何能傳文字的方式）
2. 老師在學生學習報告頁按「貼上回報碼」，貼上後按「匯入」

代碼只帶英文字、答錯次數、題型與日期；中文與單元由老師端的題庫查回來，所以不會太長
（30 個錯字約 1200 字元）。匯入會**取代**老師這台裝置上現有的學生紀錄。

### 紀錄存在哪裡

存在**使用者自己瀏覽器的 localStorage**（key: `vocabQuiz:v2`），關掉網頁不會消失。

要注意的是：

- 紀錄跟著**裝置＋瀏覽器**走。學生換手機、換瀏覽器，或清掉網站資料，紀錄就不見了
- 老師必須在**學生用過的那台裝置**上切換成老師身分，才看得到那份報告
- 無痕視窗不會保留紀錄（頁面會顯示提示，功能仍可正常使用）

## 三種模式

1. **平常測驗練習**（吊人遊戲）— 可自選單元／題型／題數，答錯滿 5 題立刻結束
2. **正式考試** — 設定不可調整：全部單元、全部題型、固定 40 題（平均分配到各單元），結束後給成績單
3. **總複習** — 從過去教過的所有單元出題，可選題型與題數

**文章閱讀** — 讀一篇約 260 字的短文，把文章裡挖空的 13–15 個單字填回去。
寬螢幕時文章在左、選項在右並固定跟隨；手機則上下堆疊，選項吸附在畫面底部（2×2 排列）。
每填一格文章就補上該字，答錯的字一樣進錯題紀錄（題型記為「文章填空」）。
文章放在 `data/articles.json`，`[[word]]` 就是挖空記號；改完跑：

```bash
node tools/apply-articles.js && node tools/validate.js
```

挖空的字**必須在題庫裡**（驗證會擋），文章其他地方出現超綱字沒關係。

**單字表** — 考試前可以先看過：本次範圍的每個字都有中文與兩句例句（例句的空格已經填回單字），
點 🔊 用瀏覽器內建語音唸出來，不需要網路也不花錢；沒有語音支援的瀏覽器就不顯示按鈕。
另外兩個分頁可以看「我的錯題」與搜尋以前教過的任何一個字（中英文都能搜）。

另外主頁的「錯題重練」會從錯題紀錄出題（可選 10／20／30／全部），答對一次該單字扣 1 次紀錄。
重練的查找範圍是**考試範圍＋總複習題庫**，所以在總複習答錯的字也練得到。

成績單上答錯的每個字都會附一句例句（空格已填回並標起來）並可以點來聽，只列出正解太少了。

## 錯題考卷（老師端）

老師打開「查看報告」後，最下面有 **📝 產生錯題考卷**：從學生錯最多次的單字出題
（可選 10／20／30／全部錯題），每題四選一，三種題型輪流，附解答。產生後有兩條路：

- **🖨 列印考卷** — 列印時只會印出考卷本身（其他畫面與按鈕都會隱藏），可以當隨堂考卷發下去
- **☁️ 指派給學生** — 存到雲端；學生打開網頁就會在最上面看到「📩 老師指派的考卷」，
  題目跟老師手上那份完全一樣。作答完記為「老師指派考卷」，成績自動同步回老師端

指派的考卷存在 Firebase 的 `/vocab/<classKey>__exam`，跟學生紀錄是不同的路徑，
兩邊不會互相覆蓋。沒有開同步時仍然可以產生與列印考卷。

題型全部是四選一選擇題：英翻中、中翻英、克漏字。

## 手機上的版面

小螢幕（375×667，iPhone SE／8 這種）是實際使用的情境，量過之後修掉的問題：

| 問題 | 現在 |
|---|---|
| 答完題後「下一題」在畫面外，每題都要捲動 | 按鈕會吸在畫面底部 |
| 頁首橫幅在作答時仍佔 110px | 作答／閱讀／成績單改用精簡頁首 |
| 最長的克漏字例句把選項擠到摺線下 | 一屏放得下四個選項 |
| 五張模式卡各 180px 高，錯題面板被推到 1,500px 以下 | 卡片改成圖示在左的橫式，每張 87px |
| 小按鈕只有 29px 高，容易按錯 | 手機上放大到 37px |

`tools/e2e-mobile.mjs` 會把上面每一項量一次，改版面前後跑一下就知道有沒有退步。

## 更新範圍

老師換教材範圍時的完整流程寫在 `HANDOFF.md`，請務必先讀過再改。重點：整批取代 `WORDS`、
同步併入 `REVIEW_WORDS`、每次都要驗證沒有重複的英文單字與中文意思。

驗證指令：

```bash
node tools/validate.js          # 題庫查重、語意重疊警告與例句檢查
```

改動身分或紀錄系統時，另外跑端對端測試：

```bash
npx http-server -p 8099 -s .    # 另開一個終端機
node tools/e2e.mjs              # 身分、紀錄、老師報告（需要 playwright）
node tools/e2e-transfer.mjs     # 回報碼跨裝置傳遞

node tools/mock-firebase.mjs    # 再開一個終端機
node tools/e2e-sync.mjs         # 自動同步
```
