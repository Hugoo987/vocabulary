# 單字大挑戰

給學生用的英文單字測驗網頁。單一 HTML 檔，開啟即可使用，不需要安裝任何東西。

單字取自中文英語教材《Chapter 1 基礎 1,200 單字》，依 Topic 編號分單元。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 網頁進入點（內容與 `vocab_quiz_v7_NEW.html` 相同） |
| `vocab_quiz_v7_NEW.html` | 目前版本的完整程式碼與題庫，**唯一的真實來源** |
| `HANDOFF.md` | 專案交接說明：功能規格、更新範圍的標準流程、注意事項 |

## 目前版本

- 版本：**v7**（頁面最上方有紅色橫幅可一眼確認）
- 考試範圍：Topic 30–34，共 **140 字**
- 總複習題庫：累積 **775 字**（Topic 04–34 教過的全部）

五個單元：Be動詞&助動詞（10）、介系詞（37）、連接詞（8）、感歎詞（5）、其他名詞（80）

## 三種模式

1. **平常測驗練習**（吊人遊戲）— 可自選單元／題型／題數，答錯滿 5 題立刻結束
2. **正式考試** — 設定不可調整：全部單元、全部題型、固定 30 題，結束後給成績單
3. **總複習** — 從過去教過的所有單元出題，可選題型與題數

題型全部是四選一選擇題：英翻中、中翻英、克漏字。

## 更新範圍

老師換教材範圍時的完整流程寫在 `HANDOFF.md`，請務必先讀過再改。重點：整批取代 `WORDS`、
同步併入 `REVIEW_WORDS`、每次都要驗證沒有重複的英文單字與中文意思。

驗證指令：

```bash
node tools/validate.js
```
