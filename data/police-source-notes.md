## 三、中文意思有修正的字

Quizlet 上的中文有些是錯的或只給了少見的意思。以下是改動意思的部分（只改分隔符號、刪重複字的不列）：

| 單字 | Quizlet 的中文 | 改成 |
|---|---|---|
| equip | 安裝 | 裝備；配備 |
| shelve | 架子 | 擱置；放上架（shelve 是動詞，「架子」是 shelf） |
| bruised | 挫折的 | 瘀青的；受挫的 |
| slightly | 瘦小地,輕微地 | 稍微地；輕微地 |
| delicacy | 謹慎 | 美味佳餚；精緻；微妙 |
| take after | 仿效 | 長得像（長輩）；個性像 |
| without a trace | 天衣無縫 | 無影無蹤；不留痕跡 |
| in due time | 及時地 | 到時候；遲早（「及時」是 in time） |
| talking into | 接受 | → talk someone into：說服某人做… |
| keeping his chin up | 替他加油 | → keep one's chin up：不氣餒；保持樂觀 |
| up one's sleeve | 準備大幹一場 | → have something up one's sleeve：留有一手；暗藏妙計 |
| compiled | 編譯的 | → compile：編纂；彙整 |
| burst out | 突然 | 突然…起來（例：burst out laughing） |
| in turn | 輪流 | 依次；輪流 |
| looking up | 仰望,欽佩 | → look up to：尊敬；欽佩（look up 是查詢／仰望） |
| run against | 相撞;偶遇 | 與…競選；撞上（「偶遇」是 run into） |
| mediated | 間接的;居間(調停)的 | → mediate：調解；居間調停 |
| go away | 出門 | 走開；離開；出門 |
| physically | 物理上 | 身體上；物理上 |
| Pandemic | 流感大流行 | （疾病的）全球大流行 |

另外 10 個字的中文在匯出時黏在一起或過長（例：principal「首長,最重要的…本金的c長,負責人;u資本,本金」），已整理成 2–3 個最常用的意思：principal、rotate、collapse、Initiative、obtrusive、intimate、latter、come off、shadow、wrinkle。

## 四、近義詞的處理

像 ban／forbid／prohibit（禁止）、in order to／so as to（為了）、occasionally／once in a while（偶爾）這類近義詞，如果同一題同時出現就會兩個都對。整理時讓它們的中文共用同一個意思（例如都含「禁止」），出題程式看到就不會把它們放在同一題。另外題目的四個選項一律是同一種詞性（片語配片語、形容詞配形容詞），避免看「的」字或長度就猜到答案。

檢查方式：每組各出 30 輪，共約 2 萬題，選項不足四個、沒有正解、兩個近義詞同時出現、詞性不一致，都是 0。
